# Start here

law itself, not by remembering it.

## The one-sentence version

Ask a legal question in English; the project looks the answer up in the official
Czech and EU registries, quotes what they actually say, and tells you how much
weight each source carries.

## The one thing to remember

**Everything here is research, not legal advice.** It is built to show you its
sources so you can check them. When something is uncertain, it should say so —
if an answer ever sounds more confident than its sources justify, that is a bug,
and worth telling the agent about.
